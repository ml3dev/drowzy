What's New
Polish & Fixes
  • Complete translation cleanup
    The 1.3.1 locale cleanup only ran on English; 23 orphaned keys still lingered in 56 other languages. Drowzy ships leaner now — every locale is trimmed to match.
  • Calmer "What's New" trigger
    This tab used to open on every minor bump (1.3 → 1.4). From 1.3.2 on, it only opens on actual major releases (1.x → 2.x). Curious? The "What's new" link in Settings still takes you here anytime.
  • Screen-reader friendly toolbar
    The search, duplicate-close, and copy-tabs buttons in the tab-list header now carry proper aria-labels, so assistive tech reads them the same way a sighted user sees them.
  • Light-mode sleeping tabs easier to read
    Suspended tab titles were dimmed too aggressively in light mode, scraping the bottom of WCAG AA contrast. Nudged up just enough to pass while still reading as "asleep."
  • Whitelist list scrolls when long
    A long whitelist used to stretch the Settings panel forever. Now it caps at a reasonable height and scrolls internally, so the rest of the popup stays where you expect it.
  • Tab list recovers from transient errors
    If a message to the service worker failed, the tab list would show "Failed to load" and then stay stuck even after the next successful poll. It now recovers on the next refresh like it should.
  • Tooltip localization & general polish
    Memory-estimate tooltips were always shown in English because the i18n key was referenced but never defined. Added the missing key, stripped a couple of unused ones, and tightened the "What's new" link to use a single consistent label.

Drowzy is free and open source. If it's saving you memory, consider leaving a quick review or starring us on GitHub.

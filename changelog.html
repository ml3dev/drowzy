What's New
What's new in 1.3.3
  • See what Drowzy will save before it acts
    The memory slot in the stats strip now shows an "available" forecast with an amber dot (e.g. ~3.4 GB available) before any tabs have been suspended yet, so you can see the value right after install instead of waiting 30 minutes for the first suspension. Once Drowzy has actually freed memory, the slot switches to a blue dot with what's been saved — same number, different meaning, now visually distinct.
  • First memory savings within 30 seconds of install
    Right after install, Drowzy now does a one-time pass over tabs Chrome reports as idle for 10+ minutes and suspends those — so you see the badge populate and memory drop within seconds instead of waiting the full 30-minute timer. Recently-active tabs are left alone. Requires Chrome 121+; on 120 the regular timer still kicks in.
  • "Keep awake" button on the suspend warning
    If you happen to be on a tab when Drowzy's about to suspend it, the warning banner now has a Keep awake button — one click bumps the timer and cancels the imminent suspend, instead of forcing you to whitelist the site or wake it back up afterward. The banner also no longer shows up on tabs you're not looking at (where it was just visual noise). Plus form-data protection now covers more input types: search, date pickers, time/week/month/datetime, color pickers, and changed checkboxes/radios.
  • Keyboard shortcuts that don't fight Office
    On Windows, Alt+S also sends mail in Outlook Web and Teams — a misfire could suspend a compose tab mid-sentence. The Windows defaults are now Alt+Shift+Z to suspend and Alt+Shift+W to wake all. macOS, Linux, and ChromeOS unchanged. Want different keys? Open chrome://extensions/shortcuts.
  • Suspend & Wake show what they actually did
    Clicking Suspend Others or Wake All now shows a toast with the actual count and freed RAM (e.g. "Suspended 8 tabs · ~1.2 GB freed"). When there's nothing to act on, the buttons disable themselves with a tooltip explaining why — no more "click does nothing" moments.
  • Smarter status under the current tab
    The status line under the active tab's domain used to always say "Active — won't be suspended." Now it tells you the actual reason: Pinned, Audio playing, Whitelisted, or System page — so you know exactly why a tab is protected.
  • Friendlier first-run tips
    The welcome page now reminds you to pin Drowzy via the toolbar's puzzle icon for quick access, and includes a one-click link to remap your keyboard shortcuts if the defaults aren't quite right.
  • Full translation coverage in 57 languages
    Every new string in this release is translated into all supported languages at launch — no English fallback gaps anywhere in the popup, side panel, or onboarding.

Drowzy is free and open source. If it's saving you memory, consider leaving a quick review or starring us on GitHub.

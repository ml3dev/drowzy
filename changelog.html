What's New
New Features
  • Polished Empty States
    The tab list and session list now show a centered icon and softer copy instead of bare gray text. The "Loading tabs..." state has a gentle pulsing moon while data arrives.
  • Rock-Steady Current Tab
    The current-tab card no longer jitters between polls. The favicon and domain now stay perfectly still instead of briefly shifting every few seconds.
  • Refined Stats Section
    The lifetime RAM hero card is toned down, each stat card has a subtle colored accent, and the numbers feel more earned without shouting.
  • Smoother Section Animations
    Sessions, Stats, and Settings now expand and collapse with a smooth grid-based animation, so the popup no longer snap-scrolls when you open a section.
  • Sections Remember Their State
    Sessions, Stats, and Settings now remember whether you had them open or closed, so every popup opens in exactly the shape you left it.
  • Memory Estimate Tooltip
    Hover over the "saved" counter or the lifetime RAM hero card to see how the number is calculated (estimated ~150 MB per suspended tab; real savings vary by page).
Improvements
  • Smaller Permission Surface
    Dropped the tabGroups permission entirely, and moved host access to on-demand so it's only requested when you turn on form protection or suspended-tab marking.
  • 22-Fix Reliability Pass
    A broad polish sweep across background logic and popup handlers: whitelist now accepts localhost and IPs, double-submit is guarded, timestamps persist across service-worker restarts, and a fresh install no longer pops the changelog on first open.
  • Smarter Suspension
    Tabs are re-checked right before being suspended, so changes you make during the warning window (pinning, starting audio, whitelisting) are respected instead of ignored.
  • Safer Session Restore
    If a session restore fails partway through, Drowzy now rolls back cleanly instead of leaving behind a half-restored window.
  • Smarter Audio Handling
    When a tab's audio stops (pause Spotify, mute a Meet, end a call), Drowzy now treats that as activity and resets the idle timer. Previously, pausing for a meeting would make the tab immediately eligible for suspension and force a full reload on resume.
  • Per-Window Badge Count
    The badge on Drowzy's toolbar icon now updates when you switch between Chrome windows, so the count always reflects the window you're actually looking at.

Drowzy is free and open source. If it's saving you memory, consider leaving a quick review or starring us on GitHub.

What's New
What's new in 1.3.4
  • Startup suspend pass now actually runs
    If you had "Suspend tabs on startup" enabled, the pass used a short timer that could be skipped when Chrome shut Drowzy's background worker down before the timer fired. Now the pass is scheduled via Chrome's own alarm system, so it survives a worker restart and runs reliably after the browser opens.
  • Suspend current tab picks a better neighbour
    When you suspend the active tab via Alt+S or the context menu, Drowzy switches focus to a sibling first. If no tab exists to the right of the active one, it now jumps to the closest tab on the left instead of skipping to whichever candidate happened to be last in the list. Smoother behaviour when the active tab is at the end of the window.
  • Welcome page respects reduced-motion
    The onboarding page's fade-in animation now honours your system prefers-reduced-motion setting. The popup, side panel, changelog, and privacy pages already did; the welcome page is now in line with them.
  • Whitelist placeholder finally matches reality
    The whitelist input has accepted full URLs (e.g. https://github.com/me/repo) since 1.3.3 because the popup strips http(s):// and www. for you. The English placeholder text was updated then; the underlying HTML default was still the old wording, which would have shown if i18n localization didn't run for any reason. The HTML default is now in sync.
  • Code-quality pass on the per-tab memory constant
    The estimate of "~150 MB per suspended tab" used for the saved/forecast stats and the "Suspended N tabs · ~M MB freed" toast is now defined once in each script instead of being repeated as a magic number. No user-visible change; the next time the number gets tweaked, it'll be a one-line edit.

Drowzy is free and open source. If it's saving you memory, consider leaving a quick review or starring us on GitHub.
